# Case study inputs

One file per case study, `case-studies/<slug>.md`, filled from what Prad supplies. The Friday run reads it and must not go beyond it.

Template:

- Client: name, or "anonymised", and whether they agreed to be named
- Problem before: what was slow, costly or missing
- What we built: features in plain English
- Tools used and their costs (tool costs only)
- Time taken to build
- Results: confirmed numbers only (time saved, enquiries, usage, quotes won)
- Client quote: exact words, and confirmation it is approved
- Visuals: screenshot or screen recording paths in this repo, or a public URL to capture
- Do not mention: anything off limits
