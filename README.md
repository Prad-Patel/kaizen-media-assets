# kaizen-media-assets

Public asset bridge for the Kaizen daily content automation.

Cowork renders the daily video and image, pushes them here, then hands the
`raw.githubusercontent.com` URL to n8n (WordPress + Google Business Profile)
and Zernio (LinkedIn / Instagram / TikTok / X).

    video/YYYY-MM-DD-slug.mp4    9:16 1080x1920 daily social video
    image/YYYY-MM-DD-slug.jpg    featured image (WP + GMB + X)

Assets are kept for history. Nothing here is secret.
